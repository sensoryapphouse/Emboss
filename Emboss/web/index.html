Help & Documentation

      

        
What Emboss Does

        
Emboss converts modern documents into properly formatted braille files (BRF, eBraille, and PEF), ready for physical embossing or digital refreshable braille displays. It interprets document structure — headings, paragraphs, lists, tables, mathematics, poetry, drama, footnotes, and tactile graphics — and lays them out according to official international braille standards.


        
Two Ways to Work

        
Emboss has two integrated modes sharing your settings and translation configurations:

        
    
          
  • Quick Mode (This Screen) — The fast route for documents you already have: drag and drop a file and get an embosser-ready BRF straight away.
    • 
          
  • Advanced Direct Braille Editor — A live dual-pane editor where you write and format with braille building live beside you, including MathLive equations, 346 formula templates, spatial tables, tactile graphics RIP, Perkins 6-key chording, read-aloud speech, and self-checking proofreader. Open it with Advanced editor → at the top of the screen.
    • 
        


        
How to Use Quick Mode

        
    
          
  1. Drag a document onto the drop area, or click Choose file (.docx · .md · .xml · .nimas · .dtbook · .epub · .html · .odt · .rtf · .txt). It is transcribed immediately and shown as a live braille preview.
    2. 
          
  2. Open Settings ⚙ to pick your translation standard, language & contraction grade, embosser hardware preset, and page geometry.
    3. 
          
  3. Click Download .brf (or choose eBraille / PEF in the editor) to save your deliverable.
    4. 
        


        
🌐 Global Localisation & 112 International Languages

        
Emboss supports full user interface localization in 112 international languages (with Right-to-Left orientation for Arabic, Hebrew, Persian, and Urdu) and over 142 braille translation tables. Customize your preferred UI language and document translation tables in Settings ⚙.


        
Working with Document Structure

        
Emboss reads document structure rather than visual styling. In Word, apply Title and Heading 1–3 styles for headings, and standard bulleted/numbered lists for lists. In Markdown or HTML, use semantic heading and list tags. House-style choices (indented 3-1 vs block paragraphs, quotation mark exchange, and list formats) can be customized in Settings ⚙.


        
Maths & Equations (MathCAT)

        
Emboss transcribes mathematics using MathCAT into UEB maths (UKAAF) or Nemeth Code (BANA). Word equations (Alt + =), LaTeX math ($...$ or $$...$$), and MathML (<math>...</math>) are transcribed with full code-switch indicators.


        
📊 Spatial Tables & Advanced Formatting (BANA & UKAAF)

        
Emboss automatically transcribes tabular data into standard Spatial Columnar Tables with aligned columns and 2-cell gutters, falling back to Listed Table format when tables exceed page width. It also supports formal Transcriber's Notes (TN_OPEN/TN_CLOSE), BANA §12 Footnotes (1-3 margin), Boxlines (333 / 777), Play dialogues, and Verse stanzas.


        
🖼 Tactile Graphics & Anti-Slicing (Experimental)

        
Emboss includes an experimental page-boundary anti-slicing engine that ensures tactile diagrams never get cut across page breaks, and rasterizes vector SVGs directly into ViewPlus Tiger 8-height 3D relief and Index Braille floating-dot streams. (Note: Tactile graphics rasterization is an experimental feature currently in active development.)


        
🖨 Modern Driverless Embosser Spooling

        
Emboss allows you to punch pages directly to braille embossers from Chrome, Edge, and Opera without installing proprietary drivers:

        
    
          
  • Wireless Bluetooth Low Energy (Web Bluetooth): Direct pairing with ESP32-S3, RP2350, nRF52, and Nordic UART bridges via Custom GATT Profile (0xFEB0) with adaptive MTU chunking and live telemetry.
    • 
          
  • Universal Driverless USB (WebHID): Direct user-space output report streaming that bypasses Windows usbprint.sys and macOS CUPS kernel driver locks.
    • 
          
  • Network REST / IP: Direct local IP spooling via HTTP POST (/api/print) or network socket bridges.
    • 
          
  • USB Serial (WebSerial): Virtual COM port communication with automatic hardware profile identification.
    • 
        


        
Standards

        
UKAAF follows the UK layout guidance (38×25 default); BANA follows the US guidance (40×25 default), including the braille page number on the last line rather than the first.
