    Help

    Something not working?

    Emboss turns what you write into braille. Type in the text pane on the left and the braille appears on the right as you go. Click a word on either side to see its match on the other side; the braille rules used for it appear in the explanation bar at the bottom of the screen. While you type, the bar keeps its last explanation and updates when you pause. It is hidden while the maths keyboard is open and in a small window (narrower than 700 pixels or lower than 520), and you can turn it off in Settings › User Interface › Show the explanation bar. Screen readers still hear the explanations.

    Shortcuts are written for Windows. On a Mac, use ⌘ (Command) instead of Ctrl, and Option instead of Alt.

    The editor is made for a computer or tablet. On a phone, Emboss works in Quick Mode only.

    Making formal braille books? Switch on Settings › Advanced Production › Transcriber tools for the transcriber section of this help.

    Open a document

    • Choose Load, or drag a file onto the Emboss window.
    • Emboss reads Word (.docx, and the older Word 97–2003 .doc; also Word templates and macro documents: .dotx, .docm, .dotm, .dot), OpenDocument text (.odt), EPUB (.epub), web pages (.html), Markdown (.md), Rich Text (.rtf), plain text (.txt) and NIMAS or DAISY files (.xml, or a NIMAS package .zip). If the Load window does not offer an .odt file, drag it onto the window instead.
    • Emboss follows the document's structure. Headings, lists and tables made with the proper tools (for example Word's Heading styles) become braille headings, lists and tables. A Word list nested in Word's usual bullets (a dot, then a small circle, then a small square) becomes an ordinary nested list in braille; a bullet the author chose specially, such as an arrow or a tick, keeps its own shape. Text that only looks like a heading because it is large or bold stays ordinary text.
    • Loading a file replaces the document you have open. If you have unsaved changes, Emboss asks first.
    • The Title field above the text holds the document's title, taken from the file. It is not part of the text. In braille, with BANA it goes at the top of the first page and in the running heads; with UKAAF it is the running head, from braille page 2 (so a one-page document shows no title). Change it there. With no title of its own, the document's first heading is used. The field is shown with Transcriber tools on; anyone can show or hide it with Show the Title field above the text in Settings › User Interface. Hidden, no title is added to the braille: the text's own headings are brailled as usual, and a saved NIMAS file still keeps the title.
    • If part of a file could not be read, a notice at the top of the screen says so.
    • Emboss cannot read PDFs, pictures, spreadsheets or slides. Such a file is refused with a message that lists the formats Emboss can read, and the document you have open is left as it was. For a PDF, open it in Word or Google Docs, save it as a Word document (.docx) and load that.
    • Quick Mode takes you to the simple converter: drop in a file and export the braille. Your document goes with you, without any questions. Emboss opens at Quick Mode unless you turn off Settings › User Interface › Start in Quick Mode; switching between Quick Mode and the editor does not change that setting.

    Write and choose styles

    Every paragraph has a style. Choose it from the style list at the start of the toolbar (it shows Body Text), or type / at the start of a line or after a space, then type part of the style's name. Use the arrow keys to pick from the menu and press Enter; Esc closes it.

    • Body Text: ordinary paragraphs.
    • Heading 1, Heading 2 and Heading 3. A document's own title (for example Word's Title style, or a Markdown file's first heading) stays its title: it is brailled and saved as the title. Choosing another style for it makes it an ordinary block.
    • Bullet List and Numbered List. In a list, Tab moves an item in a level and Shift+Tab moves it back out; the Indent and Outdent buttons do the same. A list item can hold more than one paragraph: press Enter to start a new blank list line, then Ctrl/⌘+Shift+Enter (or Continue Item in the / menu) to turn it into a further paragraph of the item above instead of a new item — it carries no marker or number of its own and sits at the item's runover indent. Press it again to turn that paragraph back into an ordinary new item.
    • Table: see Insert, below.

    With Transcriber tools on (Settings › Advanced Production) the list also offers:

    • Plain List (no bullets or numbers) and Exercise Question: numbered questions. Indent an item to make a sub-question.
    • Blockquote: a quotation set apart from the text.
    • Computer Code: program code and other displayed computer text. Its spaces and lines are kept, and it is brailled as a grade 1 passage. Enter starts a new line of the same code; Enter on an empty last line takes you back to ordinary text.
    • Poetry / Verse: poems and songs, one print line per line.
    • Play Dialogue and Stage Direction: for scripts.
    • Caption (for a picture), Attribution (the author or source line under a quotation or poem) and Footnote. In a footnote, Enter starts another paragraph of the same note; Enter on that empty paragraph takes you back to ordinary text.
    • Transcriber Note: a note from the person making the braille. In braille it is marked with transcriber's note signs.
    • TOC Entry (a contents line, with its page number at the right margin) and Index Entry.
    • Sidebar Box and the listed table style: see Insert, below.

    A style that is already in a document always shows in the list while the cursor is in it, so you can change it.

    Bold, italic and underline (the B, I and U buttons) are shown with the braille signs for them. Headings are an exception: braille headings do not show print emphasis.

    When a document has headings, a Table of Contents panel above the text lists them. Click a heading there to go to it: the page moves to it and the cursor goes to the start of the heading.

    Insert maths, tables and more

    The Insert menu in the toolbar has:

    • Equation (Ctrl+E): type the maths in the equation box. It is brailled in UEB maths or Nemeth, as chosen in Settings. To leave the equation, press Esc, or the arrow keys at its start or end. The keypad button at the end of an equation opens the on-screen maths keyboard; press it again to close it.
    • Equation Templates: ready-made formulas to choose from.
    • Table: a table with three rows and three columns; the first row holds the column headings. The buttons above the table add or remove rows and columns, or delete the table; with Transcriber tools on they also change how it is laid out in braille. If a table is too wide for the braille page, Emboss lays it out another way and says so on the table.
    • Sidebar Box: text in a box, with box lines above and below it in braille. To take the box away and keep its text — its title heading included — as ordinary paragraphs in place, put the cursor in the box and choose Remove box: the /unbox command in the / menu, the Unbox toolbar button (shown only while the cursor is in a box), or Ctrl+Alt+U. This is different from the box's own Draw the box lines field in the Braille formatting dialog (Transcriber tools): that keeps the box but switches its border lines on or off in braille, while Remove box gets rid of the box itself, so the braille then has no box lines at all.
    • Break: a break between sections (three asterisks in print).
    • Print Page: marks where a new page of the print book starts, so a braille reader can follow page references. Emboss gives it the next page number; you can change the number in the marker.

    The ⠼⠋ button (just ⠼ in a narrow window; Ctrl+Shift+K) switches on six-key braille typing, as on a Perkins brailler: F D S are dots 1 2 3 and J K L are dots 4 5 6. Press the keys of a cell together and let go. Space, Enter and Backspace work as usual; Esc switches it off. A paragraph made only of braille you typed comes out exactly as you typed it: from cell 1, with your spaces and line breaks, wrapped only where a line is longer than the braille page.

    Pictures

    • A picture in a loaded document shows as a card with a box headed Description for the braille reader. What you type there is what the braille reader is told about the picture: Emboss puts it in a transcriber's note. Leave it empty for a picture that is only decoration. If a picture has no description, Emboss lists it under transcription warnings (see Checking the braille).
    • To remove a picture, table, tactile graphic or equation, use the Delete button on it, or click it (or move onto it with the arrow keys) and press Delete or Backspace: the first press says what is selected, the second removes it. Undo brings it back.

    Save and reopen your work

    • Save (Ctrl+S) downloads your document as a file you can open again in Emboss. It is a NIMAS file (.xml), the standard format for accessible school books, which other braille tools can read too. If the file you loaded had pictures, or was a NIMAS package, Save makes a NIMAS package (.zip) instead, so the pictures are kept. Your browser puts the file in your Downloads folder.
    • To carry on later, Load that file. Styles, print page numbers and Braille formatting choices come back with it.
    • Settings such as the braille code and page size belong to Emboss on this computer, not to the document.
    • Emboss does not save to a file automatically. It does keep a backup of unsaved changes in this browser, about every 30 seconds, and offers to bring them back if the page closes unexpectedly. The backup is not a substitute for Save. If you try to close the page with unsaved changes, your browser asks first.
    • Clear empties the document. Undo (Ctrl+Z) brings it back.

    Download the braille

    The Export menu at the top right offers:

    • Braille (BRF): the usual file for embossers and braille notetakers.
    • eBraille (.ebrl): the newer digital braille format for braille displays and reading apps. It keeps the document's headings, lists and tables, with a contents list and the print page numbers, so a reader can move around it, and it reflows to the width of the display.

    Emboss on paper

    Most people download the BRF file and send it to their embosser with the embosser's own software. Emboss can also send the braille straight to an embosser connected by a USB cable or over the network: press Ctrl+Shift+\ to show the Emboss button and the Embosser & Hardware settings (press it again to hide them). Sending over a USB cable needs Chrome, Edge or Opera.

    Read aloud

    Read (Ctrl+Shift+Space) reads the document aloud from the cursor, including maths, and highlights each word in the print and the braille. Press it again to stop. Double-click a line of braille to start reading from there. Choose the voice and speed in Settings › User Interface.

    Checking the braille

    • Emboss checks its braille by translating it back into print. If a word does not come back the same, a yellow … words to check button appears above the braille and the word is marked in the text. Select the button to go to each word in turn. Often the braille is right and the word is simply unusual, such as a name, but it is worth checking.
    • If the document uses a symbol a braille reader may not know (for example a different bullet for sub-lists, or a print symbol that has no braille equivalent), a notice at the top names each symbol and offers to add one line at the start of the document explaining them. You can close the notice instead.
    • If Emboss had to leave something out or change it while brailling — for example a character with no braille, a table too wide for the page that it laid out another way, or a picture with no description — a red … transcription warnings button appears above the braille. Select it for the list; each entry takes you to its place in the document.
    • These notices clear themselves when the document changes, and when you clear it.
    • Braille has lines that print does not: the title at the top of the first page, the running heads, the page numbers and the print page changes. Click one of these lines in the braille to see what it is and where to change it.

    Settings that matter

    Open Settings with the gear button at the top right.

    • Rules & Standards: the braille code and grade (for example English UEB, contracted or uncontracted; choose "more languages" at the end of the list to see them all), the braille standard (UKAAF for the UK or BANA for North America; the first time it runs, Emboss picks the one that matches your browser's country), and the maths code. With Transcriber tools on, also the paragraph format (indented, the usual, or block paragraphs with blank lines between them) and quotation marks. List format and table layout are here too.
    • Advanced ProductionPage size: the page size. Choose a Page size preset (US braille paper 11 × 11½ in at 38 or 40 cells by 25 lines; UK 12-inch paper or A4) or type the cells per line and lines per page; the list shows the preset that matches, or Custom size. Match it to your embosser's paper. Changing the braille standard sets that standard's usual size (BANA 38 × 25, UKAAF 38 × 27). Transcriber tools is here too.
    • User Interface: the language of the buttons and menus (this does not change the braille), showing braille as BRF letters instead of dots, the reading voice and speed, Show the explanation bar, and Start in Quick Mode (whether Emboss opens at Quick Mode or at the editor). Quick Mode and the editor share these settings.

    Working offline

    Emboss works without the internet once it has been opened with a connection. On that first visit it quietly downloads everything it needs (the braille tables, the maths engine and the fonts), and the bar at the bottom says Emboss is ready to work offline once. Help shows whether it is ready, next to the version. A new version arrives the next time Emboss is opened online.

    Transcriber tools

    You see this section because Settings › Advanced Production › Transcriber tools is on. The setting shows the controls for formal braille books. It only shows or hides controls: it never changes the braille. The layout rules that make braille correct apply whether it is on or off, and a document that already has a notes page, a symbols page or formatting choices keeps them, and saves them, with the setting off.

    With the setting on you also get:

    • the Transcriber's Notes Page and Special Symbols Page styles, in the style list and the / menu;
    • the Layout button (Braille formatting), the 1-1 (Blocked Paragraph) and 5-5 (Directions) toolbar buttons, and the Notes… and Regenerate () buttons when the document has those pages;
    • more fields in the Braille formatting dialog;
    • on a table, the layout button (Auto, Listed, Stairstep …) and Braille formatting; on a picture, Picture type (the word its transcriber's note starts with: Illustration, Photograph, Map …);
    • in Settings › Advanced Production: volume splitting and the Braille formatting options for the whole document.

    The plain notice about unfamiliar symbols is not shown while the setting is on: use the Special Symbols page instead.

    Blocked and directions paragraphs

    • 1-1 blocks the paragraph with the cursor (or every paragraph selected): it starts in cell 1 with no first-line indent (BANA 1.9.3). Press it again to undo it. To block every paragraph in the document, use Settings › Rules & Standards › Paragraph Format instead.
    • 5-5 marks unnumbered, unlettered directions, such as the instructions before an exercise, with 5-5 margins (BANA 10.3.2). Emboss never guesses which paragraphs are directions. Braille formatting has "continued" and "labelled" choices for them.

    Both apply to Body Text paragraphs only, and are greyed out when the cursor is in a heading, list, table, quote, poem or other style.

    Strikethrough (crossed-out print)

    The S button (Ctrl/⌘+Shift+X, works even with this setting off) marks crossed-out print. UEB has no ordinary sign for that, so it is brailled with the first transcriber-defined typeform (UEB 9.5.1) — its own word, symbol and passage signs, listed automatically on the Special Symbols page the first time it is used.

    Script

    The 𝒮 button (Ctrl/⌘+Shift+S, works even with this setting off) marks print set in a script or handwriting typeface — a signature, a handwritten note reproduced in the book, a decorative script heading kept as running text. Unlike Strikethrough, script is not one of the five transcriber-defined typeforms: UEB gives it its own word, symbol and passage signs (Rules of UEB, 3rd edition, §9), so it needs no entry on the Special Symbols page. It can combine with Bold/Italic/Underline on the same text. Shown in the print pane in a script-like font. Importing a document also sets it automatically where the source itself marks the text as script — a Word/.doc run in a named script or handwriting font (for example Brush Script, Lucida Handwriting or Segoe Script), or an HTML/EPUB run with a class="script" or a script/cursive font-family.

    Braille formatting dialog

    Layout (Ctrl+Alt+B, or Braille formatting… in the / menu) shows the fields for the block with the cursor; each field names the rule it follows. It is greyed out where there is nothing to choose. The fields include, for example:

    • lists: a note that explains a symbol above the list, glossary, dictionary and thesaurus layouts, stripping continuation letters;
    • headings: a heading that goes with a box, an entry-word heading;
    • poetry: line numbers and their note, counted words, wide gaps, rhyme letters, an uncontracted or displayed poem, the UKAAF poem method;
    • notes: key lists, a dot locator, cross-reference notes, mentioned symbols;
    • tables: repeating the column headings on each page, the "continued" note, the guide-dot note, ditto marks, stairstep subdivision rows, where the citation goes;
    • paragraph layout: diagrammed sentences, hanging margins, arrow lines, paragraph numbers, song information;
    • footnote mark placement, a caption identifier, print page changes (below), and fonts: ignoring print fonts, diacritic notation, leaving out emphasis.

    The choices are saved in the document. Fields hidden while the setting is off keep their values.

    Settings › Advanced Production › Braille formatting options hold the choices for the whole document, such as keeping verse lines and stanzas together, list page rules, leaving out even braille page numbers in interpoint (BANA 1.15.1f), end-of-volume statements, different bullets at each list level, running head key words, spaced ellipses, elision apostrophes, and the UKAAF print page number and poem line indicator. These are saved in the document too.

    Transcriber's notes

    • The Transcriber's Notes Page goes on its own page, headed TRANSCRIBER'S NOTES, with entries at 3-1 and no note signs (BANA 2.6).
    • When you add the page, Emboss offers suggested notes for what it found in the document: for example a picture with no caption, blocked paragraphs, a table changed to listed format, or print page numbers that are implied or combined. Nothing goes onto the page until you press Add. You can change the wording first, Dismiss a suggestion, or Add all. The Notes… button opens the suggestions again. The wording is provisional.
    • A note inside the text uses the Transcriber Note style (7-5 in BANA).

    Special symbols page

    • The Special Symbols Page goes on its own page, headed SPECIAL SYMBOLS USED IN THIS VOLUME (BANA 2.5). It lists the symbols the document uses, in braille order, and keeps itself up to date.
    • Once you edit the page, Emboss leaves it as you wrote it. The Regenerate button (, available only for an edited page) makes it automatic again. It does not yet list typeform indicators.
    • In a book of several volumes, the notes page and the symbols page appear in volume 1 only.

    Title page, running head and volumes

    • Title Page (in the style list and the / menu) puts the braille title page at the start of the book (BANA 2.3.3). Its facts — title, authors, publisher, ISBN, transcriber and so on — come from Book details… in Settings › Advanced Production, which opens by itself when you add the page. Field… (Ctrl+Shift+F) puts one of those facts at the cursor on the page, and Print title page… in the Braille menu prints it.
    • The document's title comes from the file you loaded or, for a new document, its first heading. In BANA layout the title is centred on line 1 of the first page and carried as the running head on the pages after it. If the title is too long, line 1 is left empty unless you set Running head key words in Braille formatting options (BANA 1.8.2e).
    • To split a book into volumes, set Max Pages per Volume in Settings › Advanced Production (0 keeps one volume). Each volume begins with a volume page showing the title and the volume number, and its braille page numbers start again at 1 (BANA 1.15.1d, UKAAF B004 §7). The BRF download then becomes a .zip with one file per volume.

    Print page numbers

    • Mark each new print page with Insert › Print Page (or Print Page Number in the / menu). Emboss numbers it from the previous marker, continuing roman numerals, letters and prefixes. NIMAS files keep their own page numbers.
    • In BANA layout, a page change indicator shows where each print page begins, and the print page number appears at the top right of each braille page, with a continuation letter when one print page runs over several braille pages (BANA 1.11). In UKAAF layout the print page number is shown on the page information line only when you turn that on in Braille formatting options.
    • With the cursor on a print page marker, Braille formatting offers an implied page number, a page range ("through"), a spelled-out number, combining with the next page, and an unnumbered page change (BANA 1.11.5 to 1.11.8).

    Contents

    • Type a contents list with the TOC Entry style: one line per entry, with the page number at the end (BANA 2.10). Contents lists in NIMAS files come in as TOC entries.
    • The Table of Contents panel above the text lists the document's headings; it is a way to move around the document, not part of the braille.

    The defaults Emboss uses

    Where the braille rules leave a choice, Emboss follows these defaults:

    • Paragraphs are 3-1. A paragraph is blocked only where you mark it.
    • Print emphasis is dropped from headings and kept elsewhere as print shows it.
    • Every print bullet becomes the UEB bullet, unless you turn on different bullets at each list level.
    • A table too wide for columns becomes a listed table (BANA) or paragraph form (UKAAF), unless you choose vertical division, facing pages, interchanged columns and rows, stairstep or linear. A table row is never split across braille pages.
    • In BANA layout, verse lines and stanzas are kept together, a list never starts on the last line of a page, and table column headings repeat on each new page. These keep-together rules are off in UKAAF layout.
    • Footnotes are placed at the next print page change.
    • The notes and symbols pages appear only when you insert them. "End of Volume" statements are off.
    • Emboss does not make up headings, directions, labels or line numbers: you mark them.
    • Wording Emboss writes itself, such as suggested notes and symbol names, is provisional until transcribers confirm it.
