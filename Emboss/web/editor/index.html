Help & Documentation

Two Ways to Work

Emboss provides two integrated operating modes, sharing your translation standards, language tables, contraction grades, and page geometry:

  • Quick Mode (Simple Converter) — The fast route for converting existing documents: drag and drop Word (.docx), Markdown (.md), NIMAS XML (.xml / .nimas / .dtbook), EPUB, ODT, HTML, RTF, or plain text to produce an embosser-ready BRF instantly.
  • Advanced Direct Braille Editor (This Screen) — Write, format, and edit with real-time bidirectional print↔braille synchronization, mathematical equations, formula templates, spatial tables, tactile diagrams, Perkins 6-key chording, read-aloud speech, automated proofreading, and driverless hardware spooling.

Switch back to Quick Mode at any time by clicking ← Quick Mode in the top header.

🌐 Global Localisation & 112 International Languages

Emboss is fully internationalized to support transcribers, educators, and blind students worldwide:

  • 7 Interface Languages: The user interface (buttons, menus, dialogs, tooltips, and screen reader announcements) is translated into 7 languages — German, Spanish, French, Italian, Portuguese, Arabic and Hebrew (the last two with right-to-left layout) — switch via Settings ⚙ > User Interface > Language. The language list offers all 112 languages that have braille translation tables; choosing one that is not yet translated keeps the interface in English. The interface language does not change the braille code — choose that separately in the braille settings.
  • Native Right-to-Left (RTL) Support: When selecting Arabic, Hebrew, Persian, or Urdu, the entire editor layout and document panes automatically adjust to Right-to-Left orientation with mirrored toolbars and bidirectional caret tracking.
  • 142+ Document Braille Codes: Independently select your document's braille translation tables and contraction level (UEB Grade 1/2, Spanish, French, German, Arabic, Welsh, Gaelic, Hindi, Chinese, etc.) in Settings ⚙ > Rules & Standards.

Writing, Formatting & Live Synchronisation

Type in the print pane on the left, and your formatted braille generates live on the right. Structure is what matters: real headings become braille headings; real lists become braille lists.

  • 15 BANA / UEB Block Styles: Select any style from the ¶ Body Text dropdown or type slash commands directly in the editor:
    • ¶ Body Text: Standard paragraph with 3-1 margins (/p).
    • H1 Heading: Centered major heading with blank lines before and after (/h1).
    • H2 Subheading: Section heading indented to Cell 5 (/h2).
    • H3 Sub-subheading: Minor heading indented to Cell 7 (/h3).
    • • Bullet List & 1. Numbered List: 1-3 hierarchical lists with multi-level nesting (/bullet, /number, /ul, /ol).
    • 📑 Table of Contents Entry: Indented entry with automated BANA dot leaders (_ _ _) and right-aligned print page numbers (/toc).
    • 🎭 Play Dialogue: Character dialogue with speaker in Cell 1 and speech runovers in Cell 3 (/dialogue).
    • 🎬 Stage Direction: Parenthetical stage directions indented to Cell 7 (/stage).
    • 📜 Poetry / Verse: Verse stanzas with line indents (Cell 1, runover Cell 3/5) (/poem or /verse).
    • ❓ Exercise Question (BANA §10): Numbered questions and multi-level sub-questions formatted per BANA §10. Level 1 main questions format as 1-5 (1., 2.); Level 2 sub-questions format as 3-5 (a., b.); Level 3 sub-parts format as 5-7 (i., ii.); Level 4 sub-parts format as 7-9 (A., B.) (/exercise).
    • 💬 Caption / Attribution: Italicized attribution block with 7-5 margins (/caption).
    • 📝 Footnote: Formal footnote reference with 1-3 margins (/footnote or /fn).
    • 🏷 Transcriber Note: Tinted callout box enclosed in BANA transcriber note indicators (@.< ... @.>) (/note or /tn).
    • “ Blockquote: Indented quotation paragraph (/quote).
  • Multi-Level Indentation & Outdentation: Easily structure hierarchical outlines, numbered lists, and educational exercise questions up to 5 nested levels:
    • Indent / Nest Item (Ctrl/⌘ ] or Tab): Indents the current item or selected block deeper into the hierarchy (e.g. Level 1 → Level 2 → Level 3). Also accessible via the toolbar Indent button or /indent.
    • Outdent / Promote Item (Ctrl/⌘ [ or Shift+Tab): Promotes the item higher in the hierarchy. Also accessible via the toolbar Outdent button or /outdent.
    • Screen Reader Safe: Tab is contextual and only active within lists/exercises; in standard body text, Tab allows screen reader users to navigate out of the editor without keyboard traps.
    • Live Spoken Feedback: Screen readers receive immediate spoken announcements on every level change (e.g. "List item indented to level 2 (sub-item a, b, c)").
  • Typeform Emphasis (B / I / U): Bold (Ctrl/⌘ B), Italic (Ctrl/⌘ I), and Underline (Ctrl/⌘ U) transcribe faithfully to authentic UEB typeform indicators.
  • Bidirectional Cell-Level Linking: Click any word, equation, table cell, or list item in either pane to highlight its exact matching cells in the other pane.
  • Live Style Inspector: The bottom status bar continuously displays the active style, cell indent, text alignment, and braille rule breakdown for the word under the caret.

Top Header Controls & Deliverables

  • 📂 Load: Open and import documents in any format (.docx, .md, .xml, .nimas, .dtbook, .html, .epub, .odt, .rtf, .txt).
  • 💾 Save (Ctrl/⌘ S): 1-click save to master NIMAS Project (.xml), preserving 100% of document hierarchy, BANA styles, MathML, tactile diagrams, and print page numbers with zero data loss.
  • 🗑 Clear: Clears the current document and resets the editor workspace to start fresh, with confirmation protection against losing unsaved changes.
  • Download ▾ (Braille Deliverables Menu):
    • 📱 eBraille (.ebraille): Modern DAISY/BANA digital braille package containing formatted braille, MathML, vector tactile SVGs (Experimental), and print page navigation.
    • ⠿ Braille (BRF): Universal embossed braille standard compatible with all paper embossers and refreshable braille displays.
    • 📄 PEF 1.0 (.pef): Portable Embosser Format XML with multi-volume page tables.
  • ☐ TOC (Table of Contents): Generates formal braille preliminary contents pages with an interactive outline in the editor.
  • ▶ Read: High-quality text-to-speech engine reading text and MathML equations with synchronized word lighting (Ctrl/⌘ ⇧ Space).
  • 🖨 Emboss: Direct hardware spooling across USB, Bluetooth BLE, WebHID, and Network.

🔍 Real-Time Round-Trip Proofreading & Diagnostics

Emboss automatically performs real-time round-trip verification as you type: it transcribes your text to braille with Liblouis, then back-translates the braille to text. If any word discrepancy is detected, a yellow review badge appears at the top right of the Braille view (⚠ N to review). Clicking the badge jumps directly to each discrepancy in the editor for instant review.

➕ Insert Menu: Equations, Templates, Tables, Graphics & Sidebars

  • ∑ — Equation (Ctrl/⌘ E or /math): Visual MathLive equation editor transcribed to UEB maths (UKAAF) or Nemeth Code (BANA) via MathCAT with automatic code switch indicators.
  • 🧮 — Templates (/formula): 346 searchable equations across 16 STEM categories (Algebra, Calculus, Geometry, Trigonometry, Linear Algebra, Physics, Chemistry, etc.) with math previews and spoken audio descriptions.
  • 📊 — Tables (/table or /listedtable):
    • Spatial Columnar Table (/table): Visual 2D data grid formatted per BANA §11 with column separator lines and cell gutters.
    • Listed Table (/listedtable): Row-by-row listed format for text-heavy tables (e.g. Vocabulary/Glossaries), with column headers prepended to each line.
    • Switch between Spatial and Listed modes anytime via the table header toggle.
  • 📦 — Sidebar Box (/sidebar or /box): Insert callout cards enclosed in BANA top boxlines (333 Title 333) and bottom boxlines (777).
  • 🖼 — Graphic (/graphic or /svg) [Experimental]: Insert curated STEM and educational diagrams from the 1,731-symbol library or upload custom SVG vectors. Maps colors to tactile textures and transcribes labels to Braille with protective halos.
  • 📄 — Print Page (/page): Inserts source textbook print page breaks with BANA continuous leaders or UKAAF ⠐⠤ page change lines.
  • ⁂ — Break (/break): Inserts formal section dividers ( ∗ ∗ ∗ ).
  • ⠼⠋ — Perkins 6-Key Input (Ctrl/⌘ ⇧ K): Type chords directly using home keys S D F (dots 3-2-1) and J K L (dots 4-5-6).

📐 Advanced Formatting Standards (BANA Formats 2016 & UKAAF B004)

  • Footnotes & Endnotes (BANA §12): Formatted with 1-3 margin indents (first cell 1, runovers cell 3) preceded by a blank line.
  • Transcriber's Notes (BANA §3 / UKAAF): Formatted with 7-5 margins and enclosed in official braille transcriber note indicators (@.< ... @.>).
  • Boxlines (BANA §12): Enclosed in top borders of dots 2-5 (333 Title 333) and bottom borders of dots 2-3-5-6 (777).
  • Play / Drama Dialogue & Stage Directions (BANA §13): Character dialogues format with 1-3 margins; stage directions format with 7-7 margins.
  • Poetry & Verse (BANA §13): Formatted with 1-3 margins for verse stanzas with runovers in Cell 5.
  • Table of Contents (BANA §2): Hierarchical entries with automated dot leaders (_ _ _) aligned with right-margin page numbers.

🖼 Tactile Graphics, Anti-Slicing RIP & Dynamic Displays (Experimental)

(Note: Tactile graphics conversion and rasterization into 3D Tiger and Index streams are experimental features currently in active development.)

  • Page-Boundary Anti-Slicing: Emboss automatically calculates tactile diagram heights and inserts page breaks before diagrams that would otherwise be sliced across braille sheets, ensuring every diagram starts cleanly on Line 1 of the following sheet.
  • Multi-Height 3D Tiger RIP (ViewPlus Columbia / PixBlaster): Rasterizes vector SVGs into 8 distinct physical dot elevations (Heights 0–7) with 3D tactile relief for outlines, curves, and textures.
  • Index Braille Floating-Dot Matrix: Encodes high-resolution dot-matrix packets via native ESC +g graphics streams.
  • Swell Paper / Capsule Paper (PIAF & Zy-Fuse): Renders crisp carbon-black vector outlines with 100% white background stripping for micro-capsule heat-expansion.
  • APH Monarch (32 cells × 10 lines): Direct driverless 10-line multiline braille terminal streaming and eBraille package deployment.
  • DotPad 320 Dynamic Display: Built-in 60×40 pin array simulator and direct Web Bluetooth (BLE) / WebHID connectivity.

🖨 Modern Driverless Embosser Hardware (Universal Spooler)

Emboss allows you to spool documents directly to braille embossers from Chrome, Edge, and Opera without installing proprietary drivers or utilities:

  • 1. Wireless Bluetooth Low Energy (Web Bluetooth): Direct pairing with ESP32-S3, RP2350, nRF52, or Nordic UART bridges via Custom GATT Profile (0xFEB0) with adaptive MTU packet chunking (128–512 bytes) and live telemetry notifications.
  • 2. Universal Driverless USB (WebHID): Eliminates Windows usbprint.sys and macOS CUPS kernel driver lockouts by streaming directly through user-space HID output reports for ESP32-S3, RP2040/RP2350, STM32, Arduino, Index Braille V5, and ViewPlus.
  • 3. Network REST / WebSockets / IP: Direct local IP spooling via HTTP POST (/api/print) or network socket bridges with real-time status feedback.
  • 4. USB Serial (WebSerial): Virtual COM port communication with automatic hardware profile identification (Index, ViewPlus, Romeo/Juliet, Braillo, Custom MCUs).
