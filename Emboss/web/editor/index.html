Help & Documentation

Two Ways to Work

Emboss provides two integrated operating modes, sharing your translation standards, language tables, contraction grades, and page geometry:

  • Quick Mode (Simple Converter) — The fast route for converting existing documents: drag and drop Word (.docx), Markdown (.md), NIMAS XML (.xml / .nimas / .dtbook), EPUB, ODT, HTML, RTF, or plain text to produce an embosser-ready BRF instantly.
  • Advanced Direct Braille Editor (This Screen) — Write, format, and edit with real-time bidirectional print↔braille synchronization, mathematical equations, formula templates, spatial tables, tactile diagrams, 6-key braille chording, read-aloud speech, automated proofreading, and driverless hardware spooling.

Switch back to Quick Mode at any time by clicking ← Quick Mode in the top header.

📝 Print Text Editor & Formatting Tools (Left Pane)

The print pane provides a full-featured accessible rich text editor powered by Lexical. Typing or modifying content updates the braille representation on the right in real time:

  • Paragraph Styles Menu (¶ Body): Select standard styles from the dropdown or use slash commands:
    • Heading 1 (/h1): Major title, centered in braille (BANA / UKAAF).
    • Heading 2 (/h2): Section heading with 5-5 margin indents.
    • Heading 3 (/h3): Subsection heading with 5-5 margin indents.
    • Body Text (/p): Standard paragraph with 3-1 margin indents (first line cell 3, runovers cell 1).
    • Bulleted List (/ul) & Numbered List (/ol): List items with 1-3 margin indents.
    • Blockquote (/quote): Indented quote block with 3-3 margins.
    • Exercise (/exercise): Educational question/exercise with 1-5 margin indents.
    • Footnote (/footnote): Footnote block with 1-3 margins.
    • Computer Code (/code): Code passage enclosed in UEB computer code indicators (;#).
  • Typeform Formatting: Apply Bold (Ctrl/⌘ B), Italic (Ctrl/⌘ I), and Underline (Ctrl/⌘ U). Emboss transcribes these into authentic UEB typeform indicators.
  • Markdown Shortcuts: Type Markdown prefixes directly in the print editor for quick formatting:
    • # Heading 1 · ## Heading 2 · ### Heading 3
    • * or - Bulleted list · 1. Numbered list
    • > Blockquote · ``` Code block
    • $x+1$ Inline equation · $$x^2+y^2=r^2$$ Display equation
  • Interactive Table of Contents (☐ TOC): Clicking ☐ TOC in the top header automatically parses all headings and displays a collapsible, interactive outline above the editor for instant navigation across large documents.
  • Continuous Proofreading & Contraction Inspection: Emboss continuously back-translates every line; words with contraction ambiguities or discrepancies are flagged with a gentle wavy underline. Hover over any word or press Ctrl/⌘ ⇧ D to view its exact contraction rule breakdown.
  • Synchronized Speech & Word Lighting: Click ▶ Read or press Ctrl/⌘ ⇧ Space to listen to the document read aloud with synchronized highlighting across both print and braille panes.

➕ Insert Menu: Equations, Templates, Tables, Graphics & Breaks

  • ∑ — Equation (Ctrl/⌘ E or /math): Visual MathLive equation editor transcribed to UEB maths (UKAAF) or Nemeth Code (BANA) via MathCAT with automatic code switch indicators.
  • 🧮 — Templates (/formula): 346 searchable equations across 16 STEM categories (Algebra, Calculus, Geometry, Trigonometry, Linear Algebra, Physics, Chemistry, etc.) with math previews and spoken audio descriptions.
  • 📊 — Table (/table): Insert spatial braille data tables with interactive row/column tools. Formats as BANA §11 / UKAAF §8 Spatial Columnar tables with column headers, guide lines, and 2-cell gutters, or auto-adapts to Listed Table format on narrow widths.
  • 🖼 — Graphic (/graphic): Insert curated STEM and educational diagrams from the 1,731-symbol library or upload custom SVG vectors. Maps colors to tactile textures and transcribes labels to Braille with protective halos.
  • 📄 — Print Page (/page): Inserts source textbook print page breaks with BANA continuous leaders or UKAAF ⠐⠤ page change lines.
  • ⁂ — Break (/break): Inserts formal section dividers ( ∗ ∗ ∗ ).
  • ⠼⠋ — 6-Key Braille Input (Ctrl/⌘ ⇧ K): Type chords directly using home keys S D F (dots 3-2-1) and J K L (dots 4-5-6) in either the print or braille pane.

⠿ Braille Editor Pane & Dedicated Toolbar (Right Pane)

The Braille pane on the right is an active, two-way interactive braille editor—not just a static preview. You can type, delete, reformat, and touch up braille cells directly:

  • Bidirectional Synchronization & Reverse Translation: When you edit cells in the Braille pane (via keyboard, 6-key chording, or pasting BRF), Emboss automatically back-translates the braille and reconciles the print text and document structure on the left in real time.
  • Cell-Level Interactive Linking: Click any braille cell or print word to highlight its exact corresponding counterpart in the opposite pane.
  • Braille Toolbar Controls (Top of Braille Pane):
    • Margin Preset Selector (3-1 Paragraph, Centered, 5-5 Subheading, 1-3 List, 1-5 Exercise): Instantly adjust the margin indents of the current braille line to match official BANA / UKAAF rules without switching panes.
    • Line & Cell Coordinate Badge (L1, C1/40): Real-time cursor coordinate badge showing your exact line number on the page and column cell position relative to the maximum page width.
    • Sync Status Indicator (● Synced): Visual indicator confirming that the print document and braille stream are in complete synchronization.
    • Structural Validation Badge (✓ Valid): Live structural checker verifying heading placement, blank line rules, transcriber note closures, and page line budgets.
    • INS / OVR Mode Toggle: Switch between standard text insertion (INS) and cell overwrite mode (OVR)—ideal for editing spatial math matrices and aligned braille tables.
    • BRF / Unicode Toggle: Switch the display between tactile 6-dot Unicode braille (⠓⠑⠇⠇⠕) and North American Braille ASCII (HELLO / ,HLL) for hardware displays.
    • 6-Key Braille Button (⠼⠋): Enable 6-key braille chording directly into the raw braille pane using S D F (dots 3-2-1) and J K L (dots 4-5-6).
  • Braille Slash Menu: Type / directly in the braille pane to open a dedicated braille command menu for inserting BANA boxlines (333 / 777), transcriber notes (. , ... ,.), page change lines, and spatial tables.

📊 Spatial Tables & Listed Formats (BANA §11 / UKAAF §8)

  • Automatic Layout Selection: Emboss automatically calculates the width required for each column (including 2-cell blank gutters) and generates a Spatial Columnar Table with aligned columns and separator guide lines.
  • Listed Table Format Fallback: When a table has too many columns to fit the configured page width, Emboss automatically reformats it into the official Listed Table Format (UKAAF §8 / BANA §11), presenting each row as a structured list entry with column headers as field labels.

🖼 Tactile Graphics, Anti-Slicing RIP & Dynamic Displays

  • Page-Boundary Anti-Slicing: Emboss automatically calculates tactile diagram heights and inserts page breaks before diagrams that would otherwise be sliced across braille sheets, ensuring every diagram starts cleanly on Line 1 of the following sheet.
  • Multi-Height 3D Tiger RIP (ViewPlus Columbia / PixBlaster): Rasterizes vector SVGs into 8 distinct physical dot elevations (Heights 0–7) with 3D tactile relief for outlines, curves, and textures.
  • Index Braille Floating-Dot Matrix: Encodes high-resolution dot-matrix packets via native ESC +g graphics streams.
  • Swell Paper / Capsule Paper (PIAF & Zy-Fuse): Renders crisp carbon-black vector outlines with 100% white background stripping for micro-capsule heat-expansion.
  • APH Monarch (32 cells × 10 lines): Direct driverless 10-line multiline braille terminal streaming and eBraille package deployment.
  • DotPad 320 Dynamic Display: Built-in 60×40 pin array simulator and direct Web Bluetooth (BLE) / WebHID connectivity.

🖨 Modern Driverless Embosser Hardware (Universal Spooler)

Emboss allows you to spool documents directly to braille embossers from Chrome, Edge, and Opera without installing proprietary drivers or utilities:

  • 1. Wireless Bluetooth Low Energy (Web Bluetooth): Direct pairing with ESP32-S3, RP2350, nRF52, or Nordic UART bridges via Custom GATT Profile (0xFEB0) with adaptive MTU packet chunking (128–512 bytes) and live telemetry notifications.
  • 2. Universal Driverless USB (WebHID): Eliminates Windows usbprint.sys and macOS CUPS kernel driver lockouts by streaming directly through user-space HID output reports for ESP32-S3, RP2040/RP2350, STM32, Arduino, Index Braille V5, and ViewPlus.
  • 3. Network REST / WebSockets / IP: Direct local IP spooling via HTTP POST (/api/print) or network socket bridges with real-time status feedback.
  • 4. USB Serial (WebSerial): Virtual COM port communication with automatic hardware profile identification (Index, ViewPlus, Romeo/Juliet, Braillo, Custom MCUs).

🌐 Global Localisation & 112 International Languages

Emboss is fully internationalized to support transcribers, educators, and blind students worldwide:

  • 112 Interface Languages: Switch the complete user interface (buttons, menus, dialogs, tooltips, and screen reader announcements) into 112 languages via Settings ⚙ > User Interface > Language. Common languages (English, Spanish, French, and your local system language) are pinned to the top of the list for quick access.
  • Native Right-to-Left (RTL) Support: When selecting Arabic, Hebrew, Persian, or Urdu, the entire editor layout and document panes automatically adjust to Right-to-Left orientation with mirrored toolbars and bidirectional caret tracking.
  • 142+ Document Braille Codes: Independently select your document's braille translation tables and contraction level (UEB Grade 1/2, Spanish, French, German, Arabic, Welsh, Gaelic, Hindi, Chinese, etc.) in Settings ⚙ > Rules & Standards.
